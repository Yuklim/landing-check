# 生成提示词 · 可直接粘贴

AI 创作软件里生成，**16:9 横画幅，视频**。每条已经把人物、场景、构图留白、光线风格拼成一整段，复制整段粘过去即可，不用再拼。

**三件事决定成败**

1. 每条都上传同一张定妆照做参考图，人物才不会换脸。
2. 标「叠界面」的镜头，左侧三分之二必须是干净的空，后期要把手机界面和放大卡浮在那里。
3. 人物手里的手机，屏幕一律背对镜头。AI 生成的屏幕是乱码，而且左边已经有一块真实界面，两块屏幕会打架。

**负面提示词（每条通用）**

```
文字、字幕、水印、logo、招牌、海报、手机屏幕内容、多人、人群、杂乱背景、强烈图案、广角畸变、剧烈运镜、镜头抖动、低画质、过曝、肢体畸形、多余手指
```

```
text, subtitles, watermark, logo, signage, posters, phone screen content, multiple people, crowds, cluttered background, strong patterns, wide-angle distortion, fast camera movement, shaky camera, low quality, blown highlights, deformed limbs, extra fingers
```

生成好按 `footage/README.md` 的文件名放进 `footage/`，重跑 `python3 demo/video/render.py` 即自动接上。时长按下表；工具出不了那么长就出最长档，渲染器会把短素材做往返循环补足。
