# Landing Check｜外国游客落地中国的第一小时助手

> **帮助外国自由行游客在落地中国后的第一小时，快速解决上网、支付和前往酒店三个最关键的问题。**

Landing Check 是 Trip.com App 内的一个入境游辅助功能。

它不试图再做一个完整的“中国旅游助手”，而是聚焦游客最容易手忙脚乱的时刻：**从起飞前准备，到飞机落地，再到顺利抵达酒店。**

当用户不知道“哪里出了问题”时，可以通过「我卡住了」上传截图，由 AI 判断当前场景，并从经过核验的知识库中给出下一步操作。

---

# 1. 问题与需求

## 1.1 为什么关注入境游客的落地体验？

中国入境旅游正在快速恢复。2026 年上半年，外国人入境达到 **2291.4 万人次，同比增长 20.4%**；其中免签入境外国人达到 **1781.5 万人次，占 77.7%**。随着签证、支付和住宿等便利化措施持续推进，“能不能来中国”正在变得越来越容易。

但**入境更容易，并不意味着落地后的旅行体验已经足够顺畅。** 中国旅游研究院《2024 中国入境旅游发展年度报告》仍将英文电子地图、热门景区预约、境外 App 登录和语言障碍等列为外国游客在华旅行中的堵点。2025 年杭州入境游客调研也显示，在住宿预订过程中，部分游客仍会遇到国内平台英文支持不足、国际支付不便和沟通效率低等问题。

与此同时，解决单点问题的工具其实已经越来越丰富：

- 上网有国际漫游、eSIM 和机场 Wi-Fi；

- 支付有支付宝、微信支付；

- 出行有滴滴、地图和公共交通；

- Trip.com 已经承载机票、酒店和行程信息。


因此，问题正在发生变化：

> **游客缺少的已经不只是某一个工具，而是在陌生场景下快速判断：我现在缺什么、哪里出了问题、下一步应该做什么。**

现有服务大多解决一个具体任务，但当网络、支付、出行等问题连续出现，或者正常流程发生异常时，游客仍需要自己在多个 App、攻略和帮助页面之间寻找答案。

---
## 1.2 我们聚焦“落地后的第一小时”

基于上述问题，我们没有尝试解决外国游客在中国旅行中的所有需求，而是进一步把场景收窄到：

> **起飞前准备 → 飞机落地 → 联网 → 支付 → 前往酒店**

我们把这一阶段定义为“落地后的第一小时”，因为它同时具备三个特点：

- **问题高度集中。**  网络、支付、交通等基础任务往往在很短时间内连续发生，一旦其中一个环节失败，会直接影响后续行程。

- **任务前后依赖。**  没有网络，会影响支付、打车和查询信息；支付没有准备好，又会影响交通和消费。这不是几个孤立的问题，而是一条连续的任务链。

- **用户处理问题的能力最低。**  游客刚经历长途旅行，可能不懂中文、没有中国手机号，甚至暂时没有网络。此时让用户阅读长攻略、切换多个 App、重新判断解决方案，本身就会增加负担。

因此，我们认为，“落地后的第一小时”不是一个泛化的旅游场景，而是一个**问题密度高、时效性强、适合主动介入的关键节点**。这也决定了 Landing Check 不适合再做成一个需要用户额外下载、注册和学习的独立 App。

Trip.com 已经拥有用户的航班、落地机场、酒店订单等行程上下文，也已经是游客出发前和旅途中会持续使用的入口。Landing Check 可以直接利用这些已有信息，在航班落地等关键节点主动出现，而不是要求游客重新描述自己的情况。

因此，我们把 Landing Check 定义为 **Trip.com 内面向入境游客的场景化辅助功能**：围绕 **上网、支付、到酒店** 三个最关键的落地任务，判断当前状态、识别异常，并只提供此刻最重要的下一步。

> **不是再给游客一个新的工具，而是让已有工具在正确的时间真正用得起来。**
