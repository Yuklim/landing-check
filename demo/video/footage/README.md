# 生成好的镜头放这里

文件名决定它进哪一镜，`render.py` 会自动接。支持 mp4 / mov / m4v / webm。
素材比镜头短会定格最后一帧，长则截断。分辨率任意，渲染时按需缩放裁切，建议 1080p 以上、25 fps。

## 分屏右侧（竖构图，768×1080 的取景，拍成竖幅或中心构图最稳）
两种放法，优先用前者：

**按镜单独生成** `<镜号>-r.mp4`，例如 `1-3-r.mp4`、`2-4-r.mp4`。

**多镜共用**（提示词包里的 R1 到 R5，各 6 秒）
| 文件名 | 用在哪几镜 | 画面 |
|---|---|---|
| `R1.mp4` | 1-2 1-3 1-4 1-5 2-6a 3-2 | 平静看手机 |
| `R2.mp4` | 2-1 2-2 2-3 | 皱眉往后靠 |
| `R3.mp4` | 2-4 | 边看边点头 |
| `R4.mp4` | 2-6b 2-7 | 笑，往后一靠 |
| `R5.mp4` | 1-6 2-5 | 一手卡一手机照着做 |
| `3-4.mp4` | 3-4 4-1 | 大厅边走边看手机 |
| `4-4.mp4` | 4-4 5-1 | 后座看窗外、笑着截图 |

R1 会在 6 个镜头里重复出现，看得出来。要讲究就按镜单独生成，用 `<镜号>-r.mp4`。

放好之后跑 `python3 demo/video/render.py`，没有对应文件的镜头继续用占位卡。
