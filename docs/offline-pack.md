# 离线旅行包 · 浦东机场 T2

本版本在原 H5 中增加真实的离线保存能力，默认英文界面，地址和沟通卡提供中文。首页、行前检查、My Trips、联网和交通相关页面均有入口，也可直接进入 `#offline`。

## 本地运行

无需后端即可体验离线包。在仓库根目录运行：

```sh
python3 h5/build_offline.py
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/h5/index.html#offline>。Service Worker 需要 HTTPS 或 localhost，不能通过双击 `file://` 使用。手机访问普通局域网 HTTP 地址通常不满足安全上下文要求，手机真机应使用 HTTPS 测试环境。

需要检查现有模拟行程导入和其他后端功能时，使用 Python 3.10+（本次测试为 3.12），按[开发指南](development.md)启动 FastAPI，打开 <http://127.0.0.1:8000/app/index.html#offline>。没有后端时仍可从随包保存的演示行程中查看酒店样例；样例需用户确认才会保存，并持续标为 DEMO。

离线包可随现有 H5 静态文件一同发布；保留完整目录结构，并在发布前生成资源清单。线上访问入口为 `/landing-check/h5/index.html#offline`。

## 功能及演示

- **酒店地址**：手动填写，或审核模拟行程中的酒店信息；中英文名称和地址必须由用户确认。支持离线编辑、全屏大字、复制及拨号。电话可不填，此时不出现可拨打的虚构号码。
- **地址与沟通卡**：按地点或场景分类，提供机场联网协助、一站式服务中心、通信窗口及携程换汇候选点。共 25 张沟通卡。插图用于识别标识，不是现场照片、楼层图或导航地图。
- **联网向导**：Wi-Fi → 认证／人工协助 → SIM／eSIM；已有支付方式直接继续，需现金才进入换汇。双语请求按用户所选情况变化，例如认证失败、找不到认证设备、柜台关闭、支付失败和 eSIM 安装缺少网络；寻找服务点时附带双语名称。请求有行内预览、大字展示和复制，离线运行，不调用 AI。支持返回上一步、求助后返回、进度与对应请求持久保存；兼容旧版已保存进度。仅在用户明确确认后记录联网成功。
- **求助与联系**：离线请求卡、酒店与机场联系方式、自建联系人。拨号需要电话信号，在线客服需要互联网。原页面的 I’m Stuck 入口在设备报告离线时转入本地求助，不调用 AI。

可复现演示：

1. 打开离线包，进入酒店页，填写并确认双语名称和地址；也可审核导入演示酒店。
2. 返回离线首页，点击 **Save for offline use**，等待 **Public guide saved**。公共指引下载与酒店保存分别显示，不用模拟订单里的下载状态冒充本机状态。
3. 在浏览器开发者工具中设置网络 Offline；关闭页面，在同一浏览器配置中重新打开原地址。
4. 进入 **Get connected**，选 Wi-Fi 失败，再进入人工协助及实体 SIM 分支。
5. 选已有支付方式会直接进入安装；选支付失败可进入换汇，之后返回 SIM 步骤。找不到或柜台关闭时仍可展示双语请求或查看联系人。
6. 返回酒店，展示全屏中文地址卡；恢复网络后页面和进度不强制重置。

验证场景请求变化：在 Wi-Fi 中选择需要认证，再分别选择 **Authentication failed** 与 **I cannot find the equipment**。两条路径均进入人工帮助页，但预览和全屏卡分别说明“认证没有成功”和“找不到认证设备”。已保存旧版离线包时，先在离线首页点击 **Check for update**，完成后刷新；个人酒店、联系人和原有进度保留。

实际网络设置、现场购卡及柜台服务由用户在系统或现场完成；本产品只提供指引，不把点击步骤伪装成真实联网、交易或预约成功。

## 缓存、维护与隐私

- 公共资源通过原生 Service Worker + Cache Storage 保存。`offline-assets.json` 列出允许缓存的文件、字节数和 SHA-256；下载到临时缓存，逐文件验证后才发布当前版本。失败时删除临时包，保留上一个完整版本。
- 缓存只覆盖当前 H5 路径；已验证 `/landing-check/h5/` 与 FastAPI `/app/`，不扩大到仓库根、后台、API 或第三方资源。带 `?api=` 的入口可复用离线壳，API 响应不缓存。
- 酒店、个人联系人和向导进度放在本机 IndexedDB，不发送到后端，也不放进公共资源包。页面提供一次清除入口，清除后公共指引仍保留。浏览器清站点数据、存储回收或更换浏览器会影响保存，设备之间不会自动同步。
- 字体采用系统回退，离线核心不依赖远程字体、在线地图或 AI。原 H5 的其他功能和教程媒体不承诺全部离线可用。
- 修改 H5 入口、脚本、样式、素材或公共 JSON 后必须执行 `python3 h5/build_offline.py`，否则完整性校验会拒绝新包。原设计稿构建脚本也已接入离线资源及清单生成。
- 当前有完整离线包时优先读取该版本。更新由用户主动发起，更新代码在下次重新打开页面时应用，不强制刷新正在进行的任务。

## 测试

```sh
python -m pytest -q backend/tests
E2E=1 E2E_CHANNEL=chrome python -m pytest -q backend/tests/test_offline_data.py backend/tests/test_offline_e2e.py
```

浏览器测试使用真实 Service Worker 和测试 HTTP 服务，覆盖子路径、离线关闭重开、图片、个人信息、向导分支、下载失败、内容校验失败、更新回退、剪贴板拒绝、存储失败及 320px 移动布局。故障由 HTTP 服务注入，避免浏览器请求拦截无法覆盖 Service Worker 请求造成假通过。

2026-10-16 发布前完整回归（`2026.10.16.2`）：**131 项通过，1 项真实模型测试按原配置跳过**。使用 Python 3.12、本机 Chrome，通过 Playwright 验证 393×852 和 320×640 移动视口。JavaScript 语法检查、Python 编译及 Git whitespace 检查通过。测试依赖安装在临时虚拟环境，没有写入项目或修改系统 Python。

其中离线相关 **30 项检查通过**，含 9 种情况的请求变化、请求在返回／求助／断网重开后的恢复、旧版本进度兼容及原有离线回归。

手机真机 Safari、Android Chrome、电话实际接通、真实机场服务和长时间系统存储回收尚未实测。依赖中的 Starlette/httpx 有一条弃用提示，不影响本次测试结果。
