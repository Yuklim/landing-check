# Landing Check 演示视频脚本 · v3

**片长** 约 2 分 35 秒 · **基调** 日系清新、治愈、产品发布会式的 App 展示
**主线** Alex，美国人，第一次来中国，落地上海的第一小时

---

## 一、整体规范

**画面风格**
- 清晨光，丁达尔光束，暖白 + 淡青的日系色调，低对比、高亮部、肤色偏暖。
- 人物镜头统一用「以人物为圆心的平稳弧形环绕」或缓慢推拉，不用手持抖动，不用快切。
- 4K，24 或 25 fps，运动模糊开。
- 人物镜头全部 AI 生成（即梦 / 可灵 / Veo 类），每个镜头给了生成提示词，中英各一份，直接贴。
- App 画面全部用 `exports/` 里的导出图做动效，不录屏，不出现任何代码、接口、后台。

**App 展示分屏（发布会式）**
- 画布左侧约 58%：手机样机，内嵌导出图，样机轻微 6° 侧倾并缓慢回正。
- 画布右侧约 42%：主角半身，手里拿着手机，视线落在屏幕上；人物镜头比 App 画面慢半拍。
- 「重点放大」：把需要观众看清的区域剪出来，放大到 1.6 到 1.8 倍，浮在样机右上方，带柔和投影和 12px 圆角，其余区域压暗 30%。放大块出现 0.3 秒缓入，停留按脚本标注。
- 点击反馈：手指点按的位置出一个 36px 的淡蓝圆点扩散。

**声音**
- 人物台词英文，字幕双语：上行英文（白色，中粗），下行中文（浅灰，常规），底部居中，底部留 8% 安全区。
- 旁白中文，女声或中性声，语速慢，留气口。旁白不打字幕，只有人物台词打双语字幕。
- BGM：钢琴 + 轻弦乐，无鼓点，大约 70 BPM；手机通知音用 Trip.com 风格的轻「叮」。

**反复出现的角标**
每一幕右上角一枚小胶囊，字体 12px，告诉评审这一幕在证明什么。用户视角的文字，不用技术词：
`Your trip` → `Before you fly` → `When you land` → `When you're stuck` → `Verified answers` → `One next step`

### B. 人物镜头（AI 生成）
1. **先生成一张 Alex 的定妆照**：短棕发、浅色衬衫外套、黑双肩包、浅灰行李箱，正面半身，清晨光。之后每条视频都用这张做参考图，人物才能一致。
2. 按「人物镜头生成清单」生成 9 条，每条出 3 个候选取最好的。场景参考图另外准备 4 张：浦东 T2 到达大厅、旧金山公寓窗边、机舱窗、出租车窗。
3. 右侧「看手机」的半身镜头，手机屏幕生成时会是乱的，剪辑时用遮罩盖掉或让手机背面朝镜头。
4. 全部导 4K 或 1080p 的最高档，24 或 25 fps 统一。

### C. 声音
| 项 | 说明 |
|---|---|
| 中文旁白 | 约 35 句，先定稿再配。真人或 TTS 都行，要慢、要留气口 |
| Alex 英文台词 | 11 句。AI 人物对口型不稳，建议台词做成画外音，人物镜头避开正面说话的嘴部特写 |
| 司机一句中文 | 「好的，璞丽酒店。」 |
| BGM | 钢琴 + 轻弦乐，无鼓点，约 70 BPM，2 分 50 秒以上，要无版权的 |
| 音效 | 通知「叮」、点击、倒带音、识别中的呼吸音、成功音，共 5 个 |

### D. 文字素材
- 双语字幕 SRT：英文上行、中文下行，只打人物台词。
- 六个角标、标题卡、三处时间小字、片尾文案。
- 字体：Inter + PingFang SC 或 Noto Sans SC，和 App 一致。
- 英文文案找母语者过一遍。

### E. 剪辑模板
- 手机样机：iPhone 15 Pro 正面 PNG，屏幕区透明，393:852 比例。
- 分屏模板：左 58% 样机、右 42% 人物，统一一次做成预设。
- 放大块预设：1.6 到 1.8 倍、12px 圆角、柔和投影、其余压暗 30%、0.3 秒缓入。
- 点击圆点、三项状态逐个点亮、绿勾弹出，三个小动效各做一个预设复用。
- 工具：剪映专业版或 Premiere 剪主线，放大块和定格倒带用 AE 或剪映的关键帧。

### F. 校对
- 时间线：08:20、the day before、07:52、分享卡四个时间点，互相对得上。
- 画面里没有 CX 362、HKG、Sep 25 残留。
- 没有代码、接口、后台画面。
- 社交界面是自制的，没有真实品牌 UI。
- 比赛要求的时长、分辨率、文件格式、大小上限，提前确认。

### G. 建议顺序
1. 定稿旁白和台词，录音，先铺一条只有声音的时间轴。
2. 改导出图、截教程图。
3. 生成人物镜头。
4. 按声音时间轴剪画面，加放大块和动效。
5. 字幕、角标、音效、调色。
6. 校对清单过一遍，出片。
